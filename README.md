# 🎮 Tic Tac Toe Arena

A modern and responsive **Tic Tac Toe** web game built using **HTML, CSS, and JavaScript**. Play against another player or challenge an AI with multiple difficulty levels.

## 🌐 Live Demo

**Play Now:** https://aljo0123.github.io/TicTacToe-Arena/

---

## ✨ Features

* 🎮 Local 2 Player Mode
* 🤖 Play Against Computer
* 🟢 Easy AI
* 🟡 Medium AI
* 🔴 Hard AI (Minimax Algorithm)
* 🔊 Sound Effects
* 📊 Persistent Scoreboard (Local Storage)
* 📱 Responsive Design
* ⚡ Smooth Animations
* 🎨 Modern User Interface
* 🏠 Home Menu
* 🔄 Restart Game
* 🗑 Reset Scores
* 🔇 Sound Toggle


---

## 🛠️ Technologies Used

* HTML5

* JavaScript (ES6)
* Local Storage API
* Google Analytics
* GitHub Pages

---

## 🚀 How to Play

1. Choose a game mode:

   * Local 2 Player
   * Play Against Computer
2. If playing against the computer, select a difficulty level.
3. Take turns placing ❌ and ⭕ on the board.
4. The first player to align three symbols horizontally, vertically, or diagonally wins.
